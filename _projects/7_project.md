## Overview

Avicenna is a comprehensive healthcare NLP platform that transforms Electronic Medical Records (EMR) into actionable intelligence, significantly reducing the time doctors need for patient assessments.

## Architecture

- **NLP pipeline** using spaCy, SciSpacy, and AWS Comprehend Medical
- Both traditional and ML-based NLP techniques for clinical insight extraction
- **HIPAA-compliant** data processing and storage
- Integration with AWS (DynamoDB, S3, EC2)

## Tech Stack

`Python` `spaCy` `SciSpacy` `NegSpacy` `AWS Comprehend Medical` `DynamoDB` `S3` `scikit-learn` `TensorFlow`

## Impact

- Processing **500K+ patient records**
- Cut physician assessment time by **50%**
- Serving US-based healthcare and insurance providers

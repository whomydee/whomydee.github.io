## Overview

Using **Ant Colony Optimization** algorithm, proposed a better keyboard layout for the Bangla language satisfying the most popular ergonomic criteria, resulting in a layout that ensures comfort, easy learning, and health-wise benefits.

## Results

- Produced a theoretically state-of-the-art Bangla keyboard layout
- Optimized across multiple ergonomic dimensions
- Outperformed existing layouts in practice

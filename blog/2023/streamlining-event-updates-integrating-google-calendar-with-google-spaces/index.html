In my current office, we heavily use Google Calendar. The norm is such that when someone is out, away, or, there is an important event we set that with duration as an event in the Office Calendar. To spice things up — we used to have a Bot that would check up after a while if there was an event that had been added to the Calendar since the last time it checked. If it finds something like that the Bot would take the information from that event and send a notification (as a message) in our office’s common Google Space, named as — Events.

Interestingly, a couple of days back my CTO’s subscription ran out of the trial period. And, this is where I come to muscle myself up to replace that task with something I never have worked on!

So, in this guide, we’ll walk through setting up an integration between Google Calendar and a designated Google Space using Google Apps Script

Yes, you heard it right! Google has a service that anyone can use for running JavaScript Code when you wish, or as a Cronjob. The primary purpose of it is to provide communication across Google Services, say — you provide a value in a specific Google Sheet and it will change something in another Google Doc.

Anyway, Let’s dive in!

Part 1 | Setting Up Your Google Space

  • Access your Google Space, like “Events”. 🎉
  • Navigate to Space Settings > Apps & Integrations > Web Hooks.
  • Create a WebHook, name it, and even add a funky avatar! 🌈
  • Save the settings and grab the generated Webhook URL.

  • Go into the Google Calendar in which you are interested to check in for new events, for my case I am using — Office Calendar.

Part 4 | Defining Script Properties

  • Within your Google Apps Script project (our case — EventBuzz), head to Project Settings > Script Properties. It’s like adding your special ingredients!

On a serious note, it’s for security reasons. In this way, we don’t put any of our secret sauce in the code. The code becomes independent of the Secrets/Credentials it needs to work on because we are injecting it from outside. Also, if these secrets/credentials need to be changed, we can do it centrally, we don’t need to change our code.

  • Add two Properties — ‘companyChannelWebhookUrl’ (paste your Webhook URL in the value field that you added in the Events - Google Space) and ‘officeCalendarId’ (paste your Calendar ID in the value field). 🌟 And, Save. It will look something like this -
